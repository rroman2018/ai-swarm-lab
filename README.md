# AI Swarm Lab v0.1 (experimental)
Android device diagnostics, TCP LAN peer reachability, split checksum calculation, benchmark and simulated recovery.
Does NOT yet implement cryptographic trust, decentralized leadership, neural network partitioning, advanced AI or voice.
Never use on an untrusted Wi-Fi network; network traffic is plaintext.
From Windows PowerShell run: powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build-AI-Swarm-Lab.ps1
